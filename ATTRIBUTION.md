# Attribution

## Original to this project

Every building, street, prop, vehicle, the colour palette and the decor atlas (brick, tiles,
frescoes, jali, signs, flags and truck art) is generated by the code in `src/lib/lahore/` and
is original to this project, MIT licensed — see [LICENSE](LICENSE).

Display fonts come from Google Fonts under the SIL Open Font License: Bungee, Gochi Hand,
Noto Nastaliq Urdu, Noto Naskh Arabic and Noto Sans Devanagari.

## Third-party runtime assets

The files under `static/game/` are **not** original to this project. They are the character
rigs and animations (`.drc`), the eye and mouth sprites, the colour lookup table, the noise
textures and the sound effects and music, together with the Basis transcoder. They were taken
from the "Messenger" web experience by abeto (<https://abeto.co/>) while this project was being
built as a learning exercise, and the gameplay code in `controls/`, `render/` and `engine/`
reimplements that runtime's physics, camera and material behaviour.

This project is unofficial and is not affiliated with or endorsed by abeto. Those assets are
included only so the project runs; they are not covered by this project's MIT licence. Do not
redistribute them or use them commercially without permission from the rights holder. If you
intend to publish or ship this, replace `static/game/` with your own audio, character rigs and
lookup textures.

`static/draco/` is the Draco decoder from Google, Apache 2.0.
